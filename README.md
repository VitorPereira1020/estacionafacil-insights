# EstacionaFácil Insights

Projeto da disciplina Aprendizagem por Projetos - 4º ADS/SI - 2026-2.

Aluno: Vitor Pereira Soares Lopes Pestana

## Sobre o projeto
Sistema que analisa as avaliações dos clientes do estacionamento EstacionaFácil,
classifica por tipo de serviço, identifica se são positivas ou negativas e mostra
os resultados em um painel com indicadores e alertas.

## Estrutura do repositório
- docs: Documento de Visão
- diagramas: diagramas UML (casos de uso, atividade, classes e sequência)
- banco-de-dados: script SQL e modelo do banco (DER)
- prototipo: telas do protótipo (Figma)
